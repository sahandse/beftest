# بفرست

اپلیکیشن Flutter فارسی برای انتقال مستقیم و امن فایل در شبکه محلی، بدون نیاز به اینترنت.

## وضعیت توسعه

- کشف دستگاه‌های نزدیک روی شبکه محلی
- ارسال و دریافت فایل
- چندفایلی
- SHA-256 برای بررسی صحت فایل
- PIN اختیاری
- قبول/رد دریافت
- تاریخچه انتقال
- رابط فارسی RTL
- Light/Dark Mode
- بدون WebView و بدون دیتای دمو

> پروژه هنوز pre-release است. HTTPS/fingerprint، اعلان/background transfer، Share Target و QR قبل از انتشار نهایی تکمیل می‌شوند.
